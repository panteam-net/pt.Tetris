# TETRIS DUEL 3D

**Swift / iOS:** версия на UIKit с VIPER, DI, двумя игроками на iPad и сетевой
дуэлью через Multipeer Connectivity находится в [ios/README.md](ios/README.md).
Откройте `ios/TetrisDuel.xcodeproj` на Mac в Xcode.

Тетрис на Python для **двух игроков за одним компьютером**. Два поля с объёмными
кубиками, освещением и перспективой. Правила классические: фигуры двигаются по
плоскому полю 10 × 20; глубина используется в графике, а не как третья игровая ось.

## Запуск

**Windows: дважды щёлкните `start.bat`, затем нажмите Enter в игре.**
Скрипт найдёт Python и при необходимости установит pygame-ce в `.deps` внутри
папки игры. Первая установка требует интернета. После установки игра работает
полностью локально. Нужен Python 3.10 или новее.

Обычный запуск из терминала на Windows, Linux или macOS:

```sh
python -m pip install -r requirements.txt
python tetris.py
```

Зависимость: [pygame-ce](https://pypi.org/project/pygame-ce/).
В проекте нет внешних текстур или звуковых файлов: геометрия рисуется программно,
короткие звуковые эффекты синтезируются при запуске. Отсутствие аудиоустройства
не мешает играть.

## Управление

| Действие | Игрок 1 | Игрок 2 |
|---|---|---|
| Влево / вправо | A / D | ← / → |
| Ускорить падение | S | ↓ |
| Повернуть по часовой | W | ↑ |
| Повернуть против часовой | Q | / |
| Мгновенно сбросить | Пробел | Enter или Enter на цифровом блоке |
| Убрать / взять из запаса | Левый Shift | Правый Shift |

Клавиши определяются по физическому положению — переключать русскую раскладку
на английскую не нужно. Удержание клавиши движения включает повтор. Поворот,
сброс и запас срабатывают один раз на нажатие.

| Общая клавиша | Действие |
|---|---|
| Enter | Начать игру / реванш на экране результата |
| P или Esc | Пауза / продолжить |
| F1 | Справка; игра при этом остановлена |
| F2 | Новая дуэль с отсчётом |
| V | Переключить наклонный / фронтальный ракурс |
| M | Включить / выключить эффекты |
| F11 | Полный экран / окно |
| Esc в главном меню | Выход |

При потере фокуса окна игра автоматически ставится на паузу. Размер окна можно
менять. Счёт побед сохраняется между реваншами, пока открыта игра.

## Соревнование

- Оба игрока получают **одну и ту же последовательность** фигур из мешков по 7
  разных фигур, но играют каждый в своём темпе.
- Полная горизонтальная линия исчезает. За 2 / 3 / 4 линии одновременно соперник
  получает 1 / 2 / 4 мусорные строки с отверстием. Одна линия сама по себе не атакует.
- Последовательные очистки дают комбо. Повторный тетрис без обычной очистки между
  ними даёт дополнительную строку. Полностью пустое поле даёт ещё 6 строк атаки.
- Атака сначала погашает собственные входящие строки. Одновременные атаки
  взаимно сокращаются. Индикатор справа от поля показывает оставшиеся строки.
- Предупреждение длится не менее 1,5 секунды. Готовые строки поднимаются после
  фиксации фигуры **без очистки линии**, не более 8 за раз.
- Каждые 10 линий растёт уровень и скорость падения. Призрачный контур показывает
  место приземления, запас можно использовать один раз на текущую фигуру.
- **Проигрывает тот, у кого переполнилось поле.** При одновременном переполнении
  — ничья. Очки отображают результат, но не определяют победителя.

## Проверка

Логика отделена от отрисовки в `engine.py`. Проверки движка не требуют pygame:

```sh
python -m unittest discover -s tests -v
```

Проверка отрисовки без открытия окна:

```sh
python tetris.py --headless --demo --frames 5 --seed 42 --screenshot artifacts/game.png
```

Проверка клавиш, паузы, реванша и всех экранов (требует pygame-ce):

```sh
python tests/smoke_app.py
```

`--demo` показывает неподвижную демонстрационную расстановку; для обычной игры
этот параметр не нужен. `--mute` отключает звук при запуске.
